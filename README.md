# Python Learning Projects

Collection of Python projects focused on backend development, OOP, logic building, APIs, and frontend fundamentals using HTML, CSS, and JavaScript.

---

## Projects

### Library Management System
Library system built with Python modules and a web interface.

**Features**
- Book registration
- User management
- Loan system
- Modular structure
- Web interface integration

---

### Calculator Web App
Simple calculator running in the browser using JavaScript.

**Tech Used**
- HTML
- CSS
- JavaScript

---

### Unit Converter Web App
Web-based unit converter built with FastAPI and JavaScript.  
(project reference: https://roadmap.sh/projects/unit-converter)

**Features**
- Length conversion
- Weight conversion
- Temperature conversion
- Dynamic UI updates
- FastAPI backend

---

### Weather Dashboard
Modern weather dashboard built with FastAPI, Redis, and JavaScript.  
(project reference: https://roadmap.sh/projects/weather-api-wrapper-service)

**Features**
- Current weather conditions
- 7-day forecast
- Favorites system
- Search historic
- Redis caching
- Dynamic weather backgrounds
- Responsive glassmorphism UI
